## Hypothesis

The narrator-character blend ("as if roses were red" — the narrator's literary
register channeling the focalizer's assessment) is a distinct technique not
captured by the current ZF/ND cognitive mode split, requiring its own
recognition as a mode or cross-cutting phenomenon.

## Record

- created | 2026-08-31T20:00: The narrator-character blend was identified in
  the corpus analysis as a mode where the narrator's own literary vocabulary
  expresses what the focalizing character perceives or judges, without the
  character possessing that vocabulary. "As if roses were red" — the character
  notices beauty; the narrator renders that noticing in language the character
  would never use. This is distinct from FID, where the character's own voice
  and idiom color the narration ("of course she'd noticed — who wouldn't?").
  It is also distinct from pure ZeroFocalization, where the narrator states
  objective facts about the world. The blend sits in between: the content is
  the character's subjective assessment, but the form is the narrator's
  literary register. The current cognitive mode split (ZF = what is true, ND =
  how the reader encounters truth) does not have a clean place for this. It is
  not ZF because the content is subjective (the character's assessment, not
  world-fact). It is not straightforwardly ND because the narrator's register
  is doing work beyond delivering the character's perception — it is adding
  literary texture that shapes the reader's experience independently of the
  character's cognitive state. Whether this requires a third cognitive mode, a
  modifier on the existing two, or recognition as a cross-cutting phenomenon
  that operates within both modes is the open question. The blend appeared
  frequently enough in the 112-story corpus to be a real technique, not an
  edge case.
