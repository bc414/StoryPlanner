## Hypothesis

V0 through v3 are point-in-time configurations of four independently-varying
pipeline factors — model, data stream, instructions, and harness — not
paradigm shifts in their own right, so an era's outcomes are attributable to
which of those factors changed and when, rather than to the version boundary
itself.

## Origin

- date: 2026-08-31
- reasoning: Raised immediately after decomposing the AI-assisted planning
  experience into four independently-varying factors (model, data stream,
  instructions, harness). Brian's assertion, typed directly: "v0, v1, v2, v3
  are not authoritative, they are bookmarks, like git tree release version
  marks." The motivation was to stop treating an era's outcomes as caused by
  its version label and instead attribute them to whichever of the four
  factors actually changed underneath it.
