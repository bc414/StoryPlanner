# asking-a-question

Enables preparing-to-explore-a-corpus and preparing-to-verify-a-corpus.

| id | mode | instruments | reads | writes | state | description |
|---|---|---|---|---|---|---|
| write-question | hitl | | corpora question-list | question-list | built | A question Brian raises about a corpus, in a session running no activity that covers it, composed from the deliberation into an entry of that corpus's list with what raised it, or a question there withdrawn or reinstated, shown to him before it is written |

## Preconditions

Nothing. It is any hitl session in which Brian asks a question about a corpus and no
activity in hand covers the asking: a session doing no buildout work at all, one reading
hypothesis files, one building a tool, one revising the method. A question raised inside an
activity whose own processes write questions is that activity's, and is written there with
what raised it in that activity's terms — from a leads artifact, from findings, in a plan,
at a promotion, at a baselining. This is the one route for a question that arises where
none of those is running.

## write-question

The session reads CORPORA.md for the corpus Brian names, then that corpus's question list.
Which corpus the question is about is his; a question the session cannot place is asked
about, never filed by guess. It composes the entry from the deliberation, each field as its schema
says: the question as a neutral assertion, what raised it, and a suggested test if one
suggests itself. A withdrawal or a reinstatement he asks for is a line appended beneath its
entry with his reason. Whatever is to be written is shown to Brian in the chat, and written
into the list once he approves it.

## Never

Writes a question Brian did not raise, or withdraws or reinstates one he did not; enters his recall as anything but a question; files a
question under a corpus he did not name; writes an entry he has not seen; answers the
question, investigates it, or writes more of a test than a naive suggestion.
